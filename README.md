# Prizm

Prizm объединяет профессиональные гильдии. Гильдии помогают бизнесам расти с помощью профессионалов, которые умеют работать с ИИ, и ведут собственные проекты.

## Документы
0. [Преамбула](./ru/00-preambula.md): почему мы выбрали этот путь.
1. [Манифест](./ru/01-manifest.md): кто мы, во что верим и как устроены гильдии.
2. [Акселератор нового типа](./ru/02-akselerator.md): как гильдии работают с бизнесом.
3. [Устав](./ru/03-ustav.md): правила членства, репутация, роли, обмен опытом и управление.
4. [Медиа](./ru/04-media.md): первый проект гильдий. Форматы, редакция и правила публикации.
5. [Дорожная карта](./ru/05-roadmap.md): этапы развития и условия перехода между ними.

Английская версия появится позже.

## Архив
В папке [v0](./v0/) лежит первая версия манифеста. Правила гильдий, ячеек и управления из неё перенесены в устав.
